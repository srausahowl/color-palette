# Color Palette Generator

Generate random 5-color palettes, click any swatch to copy its hex, or hit Space to reroll.

## Live Demo

https://srausahowl.github.io/color-palette/

## Usage

Open `index.html` in any modern browser. Zero dependencies, zero build step.

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Tech

- Vanilla HTML / CSS / JavaScript
- No frameworks, no build tools
